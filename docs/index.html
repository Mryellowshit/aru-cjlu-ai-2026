Course overview

Three connected ways to understand intelligent systems

Students move from explicit meaning and graph structure to advanced statistical learning and deep neural representations. The emphasis is not only on using tools, but on understanding assumptions, evidence and responsible application.

01Represent

Describe entities, relationships and meaning.

02Connect

Build graphs that integrate heterogeneous data.

03Learn

Identify patterns through statistical models.

04Reason

Combine evidence, rules and learned representations.

05Apply

Build trustworthy systems for real problems.
